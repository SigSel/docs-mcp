### RS-201: clippy pedantic, åtvaringar avviste i CI { #rs-201 }

<Badges><Rule level="must">MÅ</Rule> <Profile>Applikasjon</Profile></Badges>

Clippy si `pedantic`-gruppe **MÅ** vere på, og CI **MÅ** køyre clippy med
`-D warnings`. Typen `Vec<T>` står i kode og skal stå urørt.

```toml
[workspace.lints.clippy]
pedantic = { level = "warn", priority = -1 }
```

### RS-203: Ingen unwrap i produksjonskode {#rs-203}

<Rule level="must">MÅ IKKJE</Rule>

Produksjonskode **MÅ IKKJE** kalle `unwrap()`. Bruk `?` og ein feiltype.

<Tabs>
  <TabItem label="Linux">
    Køyr `cargo clippy` i terminalen.
  </TabItem>
  <TabItem
    label="Windows">
    Køyr `cargo clippy` i PowerShell.
  </TabItem>
</Tabs>

```rust
import_this_is_not_an_import();
export fn also_not_removed() {}
let v: Vec<String> = Vec::new(); // <Badges> inni kode står att
```
